# Resellbase

Resellbase ist eine Alpha-Plattform für Reseller, die Produkte schneller finden,
vergleichen und bewerten wollen – alles an einem Ort.

## 🚀 Features (Alpha)
- Marketplace mit Demo-Seed (12+ Listings)
- Live-eBay Suche (offizielle API via Netlify Functions)
- Link-Import für Vinted & Kleinanzeigen (OpenGraph Preview)
- Vergleich von 2 Listings (Buyer / Seller View)
- Analyse: Preisrange, Sell-Speed, Titel-Optimierung
- Kein Login, keine Accounts (Local-First)

## 🧪 Status
**Alpha Version**
- eBay: Live via API
- Vinted / Kleinanzeigen: Link-Import
- Fallback: Demo-Listings

## 🛠 Tech Stack
- HTML / CSS / Vanilla JavaScript
- Netlify (Hosting + Serverless Functions)
- eBay Browse API

## 📦 Setup (kurz)
1. Repository klonen oder Dateien laden
2. `index.html` öffnen oder auf Netlify deployen
3. Für eBay:
   - Netlify Environment Variable `EBAY_OAUTH_TOKEN` setzen
   - Marketplace z. B. `EBAY_DE`

## ⚠️ Hinweis
Resellbase liefert Schätzungen, keine Garantien.
Keine Verbindung zu Vinted/Kleinanzeigen APIs (nicht öffentlich).
